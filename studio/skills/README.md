# Skills Instagram

Les 13 skills `ig-*` viennent de https://github.com/Jakeschincariol/instagram-agent-skill (licence MIT, voir LICENSE).
Le pilote les installe au début de chaque exécution :

    mkdir -p ~/.claude/skills ~/.claude/instagram
    cp -r studio/skills/ig-* ~/.claude/skills/
    cp studio/instagram/*.md ~/.claude/instagram/
